## 8 performance domains (quick list)

| Domain | Focus |
|---|---|
| Stakeholders | Identifying and engaging those affected by the project |
| Team | People delivering the project and how they work together |
| Development approach and life cycle | Predictive, agile, or hybrid methodology choice |
| Planning | Organizing and coordinating work |
| Project work | Executing processes, managing resources/procurement |
| Delivery | Achieving scope and quality |
| Measurement | Assessing performance, taking corrective action |
| Uncertainty | Navigating risk, ambiguity, complexity |

## Predictive vs. agile vs. hybrid

| Property | Predictive | Agile | Hybrid |
|---|---|---|---|
| Planning | Upfront, detailed | Iterative, near-term detail | Mixed by project component |
| Change handling | Formal change control | Readily absorbed | Depends on component |
| Best suited for | Stable, well-understood requirements | Evolving requirements | Projects with genuinely mixed needs |

## Exam quick facts

| Property | Detail |
|---|---|
| Questions | 180 |
| Framework basis | PMBOK 7 (principles + performance domains) |
| Tests | Applied scenario judgment, not definition recall |

## Common scenario-response patterns

| Situation | PMI-favored response |
|---|---|
| Team conflict | Direct, collaborative resolution at team level first |
| Scope/value mismatch | Surface to stakeholders, don't just execute original scope blindly |
| Uncertain requirements | Favor iterative/agile approach or hybrid tailoring |
