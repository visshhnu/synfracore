## Reasoning — Quick Method Reference

| Question type | Fastest reliable method |
|---|---|
| Coding-decoding | Check each letter's shift individually before assuming a uniform pattern |
| Syllogism | Sketch a Venn diagram — don't reason purely mentally |
| Blood relations | Draw a 2-line family tree as you read the statement |
| Number series | Test squares/cubes/primes/AP/GP quickly, don't fixate on the first partial match |

## English — Highest-Yield Error-Spotting Categories

Subject-verb agreement, tense consistency, preposition usage — disproportionately represented in PSU-style error-spotting questions relative to rarer grammar rules.
