# English Language — Quick Reference

## Topic map and typical weightage (Prelims)

| Topic | Questions | Key technique |
|---|---|---|
| Reading Comprehension | 7-10 | Question-first for facts; full read for inference |
| Cloze Test | 5 | Read full passage before filling any blank |
| Error Detection | 5 | Find the TRUE subject, not nearest noun |
| Sentence Rearrangement | 5 | Find the anchor sentence, chain via linking words |
| Fill in the Blanks | 5 | Check grammar AND tone/context fit |
| Phrase Replacement | 5 | Test standard collocation, not just grammar |

## RC strategy

```
1. Skim question stems first (not options) — know what to look for
2. Read the FULL passage once — mandatory for inference/tone questions
3. Factual questions → go directly to noted location
4. Vocabulary-in-context → re-substitute option into the sentence,
   don't rely on memorized dictionary meaning alone
```

## Common grammar traps

```
Subject-verb agreement:
  "The list of items IS..." (subject = "list", singular — ignore
    the nearby plural noun in the prepositional phrase)
  "Each of the students HAS..." ("each" = singular)

Prepositions:
  different FROM (not "than")
  comply WITH (not "to")
  arrive AT
```

## Para jumble method

```
1. Find the ANCHOR — introduces topic, no backward-referencing
   words ("however," "this," "such")
2. Chain remaining sentences using linking words
3. "First/last sentence given" variant = EASIER, not harder —
   two anchors already fixed
```

## Common collocations (phrase replacement)

```
make a decision (NOT "take a decision")
pay attention (NOT "give attention")
raise a concern
```

## Double-blank fill-in

```
Check the RELATIONSHIP between the two words, not just each
independently — a mismatched pair that each "fits" locally
is the specific trap.
```

## Prelims vs. Mains

| | Prelims | Mains |
|---|---|---|
| RC style | Concrete, narrative | Abstract, policy-themed, denser |
| Error task | Spot the wrong part | Select BEST replacement (sentence improvement) |
| Time pressure | Standard | Stricter per question |

## Time budgets (starting framework)

```
RC passage: 10-12 min
Cloze: 5-6 min
Error detection: 3-4 min (fastest once patterns internalized)
Para jumbles: 5-6 min
Phrase/fill-in: 4-5 min
```

## Daily practice habit

```
1 editorial-style passage (business/economy) daily
+ 3-sentence summary
+ log unfamiliar words WITH context sentence
+ personalized grammar error log (not generic revision)
```
