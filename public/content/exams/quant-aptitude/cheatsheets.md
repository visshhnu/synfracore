## Core formulas

```
Profit % = (Profit / Cost Price) × 100
Loss % = (Loss / Cost Price) × 100

Simple Interest = (P × R × T) / 100
Compound Interest: A = P × (1 + R/100)^T
2-year CI − SI shortcut = P × (R/100)²

Speed = Distance / Time
Relative speed (opposite directions) = sum of speeds
Relative speed (same direction) = difference of speeds

Downstream speed = Boat speed + Stream speed
Upstream speed = Boat speed − Stream speed
Boat speed = (Downstream + Upstream) / 2
Stream speed = (Downstream − Upstream) / 2

Work rate = 1 / (days to complete alone)
Combined rate = sum of individual rates
```

## Alligation rule (mixtures)

```
Cheaper : Dearer = (Dearer value − Mean) : (Mean − Cheaper value)
```

## Number series — systematic check order

1. Constant difference (arithmetic)
2. Constant ratio (geometric)
3. Difference-of-differences (second-order pattern)
4. Alternating/interleaved pattern
5. Position-based (squares, cubes, index relationship)
