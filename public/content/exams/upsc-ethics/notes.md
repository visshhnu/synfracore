# GS Paper 4 — Notes

## Core mental model

- GS Paper 4 tests moral REASONING under genuine tension, not factual recall or definitional memorization — a strong answer demonstrates applied judgment, not a list of memorized theories/thinkers.
- 250 marks split roughly evenly: Section A (theory) and Section B (case studies) — both reward the same underlying skill (applied ethical reasoning), tested in different formats.
- Different ethical frameworks (consequentialism, deontology, virtue ethics) can point toward different conclusions on the same dilemma — a strong answer explicitly navigates this tension rather than mechanically applying one framework and stopping.

## Applying values concretely

- The five integrity values (Probity, Objectivity, Accountability, Transparency, Non-partisanship) need concrete scenario illustration in an answer — listing them without examples reads as memorized vocabulary, not genuine understanding.
- Goleman's four EI components (self-awareness, self-management, social awareness, relationship management) map directly onto common civil service scenarios — connect them explicitly to the case, not as a disconnected separate topic.

## The 5-step case study method — each step has a distinct purpose

1. Identify ethical issues — establishes what's actually at stake before proposing solutions.
2. List stakeholders — a strong answer identifies stakeholders NOT explicitly named in the prompt (future beneficiaries, institutional trust), which a weaker answer misses.
3. Present 3-4 genuinely-considered options — even rejected options should get real consideration, not strawman treatment.
4. Choose with justification grounded in steps 1-3 — the decision shouldn't appear as an unconnected fresh assertion.
5. Short/long-term consequences — genuine downstream thinking is often where strong answers distinguish themselves.

Under time pressure: compress each step's writing, don't skip steps — marks are allocated per demonstrated skill tied to each step, not overall length.

## Balancing genuinely conflicting values

- Mains case studies deliberately pit legitimate values against each other (compassion vs. rule-following, loyalty vs. institutional integrity) — testing judgment under tension, not testing whether one value obviously "wins."
- A weak answer asserts one value trumps another without reasoning; a strong answer acknowledges both as legitimate and reasons through the specific weight each deserves given the scenario's particular facts.

## Corruption types need different responses

- Grand corruption (systemic, high-level) → needs institutional response (audit systems, whistleblowing mechanisms).
- Petty corruption (routine, small-scale) → individual integrity + reducing discretionary touchpoints (digitization).
- State capture (systematic private influence over policy itself) → needs structural safeguards (transparency, conflict-of-interest disclosure) — individual honesty alone can't counter this scale.
- Matching the response scale to the actual corruption type described in a scenario matters — misapplying an individual-level fix to a state-capture scenario (or vice versa) misses the point.

## Advanced integration

- Use multiple thinkers to illuminate DIFFERENT facets of the same dilemma explicitly (e.g., Rawls' veil of ignorance highlighting fairness to the least-advantaged, contrasted with a pure utilitarian calculation) — name-dropping thinkers without connecting their frameworks reads as memorized decoration.
- Constitutional morality (Ambedkar) is distinct from simple rule-following deontology — it specifically invokes the Constitution's deeper values (equality, justice), useful when a technically-followable action would otherwise violate those values.
- Whistleblowing answers should address: whether internal channels were genuinely exhausted, proportionality of disclosure to harm, institutional protection context (with real, honest acknowledgment of implementation gaps), and the genuine cost even of a justified whistleblowing action — don't imply the ethically correct choice is automatically cost-free.

## Preparation approach

- The realistic goal is building transferable ethical-reasoning skill applicable to novel scenarios, not memorizing a fixed set of frameworks to recite — case studies are specifically designed to present situations not seen verbatim in preparation.
