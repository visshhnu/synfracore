# JEE Main — Quick Reference

## Exam structure

```
Paper 1 (B.E./B.Tech): 90 questions, 300 marks, 3 hours
  Physics: 20 MCQ + 10 numerical (attempt any 5)
  Chemistry: 20 MCQ + 10 numerical (attempt any 5)
  Maths: 20 MCQ + 10 numerical (attempt any 5)

MCQ: -1 for wrong answer
Numerical-value: NO negative marking
```

## Two sessions

```
January + April — best score across both counts for JoSAA
Treat January as a genuine attempt, not a practice run
```

## Percentile normalization

```
Percentile = rank WITHIN YOUR SPECIFIC SHIFT, not across all
shifts/days directly. Accounts for shift-to-shift difficulty
variance. Track percentile trend across attempts, not raw score.
```

## Numerical-section strategy (no negative marking)

```
1. Scan ALL 10 numerical questions per subject first
2. Identify the 5 with clearest/fastest working method
3. Attempt those 5 — don't just go in presented order
4. Attempt ANY numerical you have partial working for —
   no downside risk to a wrong answer here
```

## MCQ strategy (negative marking applies)

```
Attempt only with genuine partial elimination (1-2 options
ruled out). Skip pure blind guesses. Same EV logic as NEET.
```

## JEE Main vs. JEE Advanced

| | JEE Main | JEE Advanced |
|---|---|---|
| Conducting body | NTA | IIT (rotating) |
| Eligibility | Class 12 pass/appearing | Top ~2.5 lakh Main rankers |
| Purpose | NIT/IIIT/GFTI + Advanced eligibility | IIT admission only |
| Style | Formula-direct | Conceptual, multi-concept |
| Attempts | Twice/year | Twice, consecutive years max |

## January → April diagnosis

```
Underperformed vs. your mock trend → exam-day execution issue
  → focus April on full-condition mocks
Performed in line with mock trend → genuine content gap
  → focus April on specific weak topics identified
```

## Preparation priorities

```
[ ] NCERT mastery FIRST — not a step to rush past
[ ] Genuine formula recall (write from memory), not just recognition
[ ] Accuracy before speed — compress time only once accurate
[ ] PYQ analysis for recurring chapters/formats, not just practice reps
[ ] Prepare for BOTH outcomes: NIT/IIIT via JoSAA AND Advanced eligibility
```
