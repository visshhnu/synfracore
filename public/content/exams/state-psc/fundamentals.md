# State PSC — Prelims Preparation (State-Specific)

## How State PSC Prelims Differs From UPSC Prelims

State PSC prelims follow the same broad GS + CSAT structure as UPSC, but roughly 30–40% of the paper is state-specific — a portion that trips up aspirants who prepare only from national-level material.

## What "State-Specific" Actually Means in Practice

| Area | What to prepare |
|---|---|
| State History | Regional dynasties, freedom movement contribution from the state, post-independence state formation/reorganisation |
| State Geography | Rivers, soil types, climate zones, mineral resources, district-wise data |
| State Polity | State legislature structure, notable amendments/acts specific to the state, local self-government (Panchayati Raj/Municipal) |
| State Economy | State budget highlights, major industries, state-specific welfare schemes |
| State Current Affairs | State government schemes, appointments, state-level sporting/cultural events from the last 12 months |

## Prelims Exam Pattern (Typical, Varies by State)

Most State PSCs run a two-paper prelims: General Studies (GS) and a State-specific/CSAT-equivalent paper, each objective-type with negative marking (commonly -0.25 to -0.33 per wrong answer). Qualifying marks for the second paper are often just a cutoff (33%) rather than a merit-ranking component — check your specific state's notification, since this varies (TNPSC, KPSC, MPSC, APPSC, and TSPSC each have different structures).

## Preparation Strategy for Prelims

1. Build the national-level GS foundation first (shared with UPSC prep) — History, Polity, Geography, Economy, Environment.
2. Layer state-specific material on top using the state board's own Class 6–10 textbooks (the single best source most aspirants underuse).
3. Track the last 3–5 years of that state's PSC prelims paper — state-specific weightage patterns repeat more than people expect.
4. Revise current affairs specifically filtered to state government announcements, not just national news.
