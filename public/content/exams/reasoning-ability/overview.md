# Reasoning Ability — Banking & SSC Exams

## Why This Section Exists Separately

Reasoning Ability is the single highest-weightage section in banking Mains exams (puzzles alone can carry 15–20 questions), and it's the section where preparation quality — not raw intelligence — determines speed. Pattern recognition built through repetition is the entire game.

## Core Topic Map

| Topic | What's tested | Notes |
|---|---|---|
| Puzzles & Seating Arrangement | Circular, linear, box-based, floor-based puzzles | Highest weightage in Mains — practice daily |
| Syllogism | Statement-conclusion validity using Venn diagram logic | Rule-based; a fixed method solves nearly all variants |
| Coding-Decoding | Letter/number pattern shifts | New patterns appear yearly — practice recent-year variety, not just old patterns |
| Blood Relations | Family tree construction from statements | Draw the tree — never solve mentally beyond 3 relations |
| Direction Sense | Displacement and final-direction problems | Sketch every question; mental tracking causes most errors |
| Input-Output | Step-by-step word/number rearrangement machine | Identify the rule from step 1→2 before proceeding |
| Inequality | Coded/direct inequality chains | Combine statements carefully; watch for "either-or" cases |

## Puzzle-Solving Method

```flow
{
  "layout": "flow",
  "steps": [
    { "label": "Read All Clues", "sublabel": "Get the puzzle's overall shape first, write nothing yet", "color": "slate" },
    { "label": "Start From the Definite Clue", "sublabel": "A fixed position or exact relationship, not clue #1", "color": "blue" },
    { "label": "Build Incrementally", "sublabel": "Mark uncertain placements distinctly from confirmed ones", "color": "purple" },
    { "label": "Re-Verify Every Clue", "sublabel": "Catches most \"trap\" arrangements exams intentionally set", "color": "green" }
  ]
}
```

1. Read all clues once without writing anything, to get the puzzle's overall shape (how many people, how many variables — seat + floor + profession, etc.).
2. Start from the most definite clue (a fixed position or an exact relationship), not the first clue in the list.
3. Build the arrangement incrementally, marking uncertain placements distinctly from confirmed ones.
4. Re-verify every clue against your completed arrangement before answering — this catches the majority of "trap" arrangements exams intentionally set.

## Prelims vs Mains Difference

Prelims reasoning is largely standalone, moderate-difficulty puzzles and direct syllogism/coding questions. Mains reasoning shifts to significantly harder puzzles (5–7 variables, incomplete/contradictory-seeming clues resolved through elimination) plus a dedicated Computer Aptitude sub-section in several banking exams.

## Study Approach

- Solve at least one full puzzle daily under a 6–8 minute timer from day one of prep — this section rewards volume more than any other.
- Maintain an error log specifically for puzzles — most mistakes repeat across similar puzzle types until consciously corrected.
