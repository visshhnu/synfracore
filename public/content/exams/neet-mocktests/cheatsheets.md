# NEET Mock Tests — Quick Reference

## Mock schedule by phase

| Phase | Activity | Frequency |
|---|---|---|
| 3 months before | Chapter-wise tests (30 min) | Daily |
| 2 months before | Subject-wise (1hr) + 2 full mocks/week | Daily |
| 1 month before | Full mocks only (3 hrs) | 1/day |
| Final week | Review only, 1-2 full mocks max | Reduced |

## Starting time allocation (personalize via mock data)

```
Biology  (90 Q, 360 marks) — ~50 min
Physics  (45 Q, 180 marks) — ~65 min
Chemistry (45 Q, 180 marks) — ~65 min
(leaves buffer for review — don't plan to use all 180 min on first pass)
```

## Negative marking — expected value

```
+4 correct / −1 incorrect / 0 unattempted

0 options eliminated (blind guess): EV = +0.25 (risky, low-confidence)
2 of 4 eliminated (50% confidence): EV = +1.5 (worth attempting)

Rule of thumb: attempt only with genuine partial elimination;
leave truly unknown questions blank.
```

## Two-pass strategy

```
Pass 1: Answer only fast, confident questions (~30-45 sec each);
        mark anything slower for later
Pass 2: Return to marked questions with remaining time
```

## Mock analysis template (every wrong answer)

```
Topic: _______
Why wrong: [ ] Concept unclear  [ ] Silly mistake
           [ ] Guessed          [ ] Unnecessary negative mark

```

## Weak-topic ranking (after every 10 mocks)

```
Rank by: frequency × mark value (marks lost), NOT raw error count
Top 5 → scheduled, dedicated revision time
```

## Spaced repetition (for mock mistakes specifically)

```
Day 0: Study fresh / log the mistake
Day 1: 30-min revision
Day 3: 15-min revision
Day 7: 10-min revision
Day 21: Quick glance / final check
```

## Score plateau — diagnosis checklist

```
[ ] Same weak topics recurring mock after mock → revision
    follow-through gap, not an analysis gap
[ ] Errors shifting to genuinely harder/rarer question types →
    content-depth ceiling, needs harder practice material
[ ] High accuracy but low attempt rate → time-management
    problem, not knowledge — fix strategy, not content study
```
