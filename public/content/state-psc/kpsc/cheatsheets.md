## Karnataka unification history quick reference

| Element | Detail |
|---|---|
| Pre-unification | Kannada regions split across Mysore, Bombay/Madras Presidencies, Hyderabad State |
| Trigger | 1956 linguistic reorganization of states |
| Result | Mysore State formed, renamed Karnataka in 1973 |

## Karnataka's regional diversity

| Region | Character |
|---|---|
| Coastal Karnataka | Fishing, coastal trade |
| Malnad/Western Ghats | Biodiversity, coffee/spice plantations |
| North Karnataka | Deccan sultanate/Vijayanagara history, distinct development patterns |
| Bengaluru-plateau | IT-sector economic hub |

## Preparation strategy by exam

| Exam | Focus |
|---|---|
| KAS | Full GS depth + Mains answer-writing practice |
| FDA/SDA | Preliminary-level objective recall focus |

## Common preparation pitfalls

| Pitfall | Correction |
|---|---|
| Treating Karnataka as one undifferentiated region | Study each sub-region's distinct history/economy |
| Uniform prep depth across KAS/FDA/SDA | Calibrate depth to targeted exam's actual stages |
| Skipping dedicated Mains-writing practice | Practice timed, structured answers as a distinct skill |
