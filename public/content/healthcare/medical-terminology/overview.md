# Medical Terminology

## Why This Comes Before Everything Else

Every ICD-10-CM code, CPT code, and clinical note is built from medical terminology. Skipping this and jumping straight to coding guidelines is like learning to read code without learning the alphabet — you can memorize individual codes, but you can't decode a term you've never seen before. This is the true starting point of a medical coding career, before ICD-10-CM Fundamentals.

## The Word-Building System

Medical terms are built from three parts: **prefix + root + suffix**. Once you know the common pieces, you can decode thousands of terms you've never explicitly studied.

```
hyper- / gastr / -itis
(above/excess) (stomach) (inflammation)
= "excessive inflammation of the stomach"
```

## Common Roots (by body system)

| Root | Meaning | Example term |
|---|---|---|
| cardi/o | heart | cardiomyopathy |
| gastr/o | stomach | gastritis |
| nephr/o, ren/o | kidney | nephrectomy, renal |
| hepat/o | liver | hepatitis |
| dermat/o | skin | dermatitis |
| oste/o | bone | osteoporosis |
| neur/o | nerve | neuropathy |
| pulmon/o, pneum/o | lung | pulmonary, pneumonia |

## Common Prefixes

| Prefix | Meaning | Example |
|---|---|---|
| hyper- | excessive, above normal | hypertension |
| hypo- | deficient, below normal | hypoglycemia |
| brady- | slow | bradycardia |
| tachy- | fast | tachycardia |
| a-/an- | without, absence of | anemia |
| dys- | difficult, painful | dyspnea |

## Common Suffixes

| Suffix | Meaning | Example |
|---|---|---|
| -itis | inflammation | appendicitis |
| -ectomy | surgical removal | appendectomy |
| -otomy | surgical incision | tracheotomy |
| -ostomy | surgical opening | colostomy |
| -algia | pain | neuralgia |
| -ology | study of | cardiology |
| -pathy | disease | neuropathy |
| -emia | blood condition | anemia |

## Applying This to Coding

When you encounter an unfamiliar term in a physician's note — say "nephrolithiasis" — break it down: **nephr/o** (kidney) + **lith** (stone) + **-iasis** (condition of) = "condition of kidney stones." This directly points you toward the correct ICD-10-CM chapter (Diseases of the Genitourinary System) even before you look up the exact code.

:::tip Study approach
Don't try to memorize thousands of whole words. Memorize the ~50 most common roots, ~20 prefixes, and ~20 suffixes — that combination decodes the vast majority of terms you'll encounter in real clinical documentation.
:::
