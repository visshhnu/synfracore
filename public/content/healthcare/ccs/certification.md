## Eligibility Pathways (per AHIMA)

Meet **at least one** of the following before sitting the CCS exam:

1. Coursework in anatomy, pathophysiology, pharmacology, medical terminology, reimbursement methodology, ICD diagnostic coding, and CPT/HCPCS coding — **plus** one year of direct coding experience
2. Minimum two years of related coding experience
3. Current **CCA** credential plus one year of experience
4. A coding credential from another organization plus one year of experience
5. Current **CCS-P**, **RHIT**, or **RHIA** credential

## Exam Content Domains

AHIMA's published content outline organizes the exam into five domains:

1. **Coding Knowledge and Skills** — the largest practical share of the exam: ICD-10-CM, ICD-10-PCS, and CPT/HCPCS code assignment across both inpatient and outpatient scenarios
2. **Coding Documentation** — reading and interpreting clinical documentation to support code selection
3. **Provider Queries** — recognizing when documentation is insufficient and a compliant physician query is needed, rather than guessing or defaulting to an unspecified code
4. **Regulatory Compliance** — coding compliance, fraud/abuse awareness, and adherence to official coding guidelines
5. **Information Technologies** — familiarity with the health IT/EHR context coding work happens within

## Code Sets Tested

ICD-10-CM (diagnosis, both settings), **ICD-10-PCS** (inpatient procedures — this technology's core new-content focus), and CPT/HCPCS (outpatient facility procedures).

## Preparing With This Technology

1. Confirm your existing outpatient ICD-10-CM/CPT knowledge is solid (this platform's `icd-10-cm`/`cpt` technologies) — CCS builds on that rather than re-teaching it
2. Work through this technology's **Fundamentals** (PCS structure) and **Intermediate** (root operations, table coding) sections until you can build a 7-character PCS code from documentation, position by position, without guessing
3. Work through **Advanced** for inpatient-specific sequencing (UHDDS principal diagnosis, POA indicators, DRG/CC-MCC awareness)
4. Practice the coding scenarios in this technology's **Projects** section, timed
5. Review **Interview** Q&A for both technical recall and the reasoning AHIMA's exam and real employers expect

## Study Timeline

Given CCS assumes prior outpatient coding competency and adds a genuinely new code set (ICD-10-PCS) plus inpatient-specific rules, most candidates already holding CPC/CCA-level knowledge need **8-12 weeks** of focused PCS/inpatient-specific study — meaningfully less than starting medical coding from zero, since the diagnosis-coding and documentation-reading skills carry over directly.
