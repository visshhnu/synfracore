# ICD-10-CM — Portfolio Projects

Build coded work that shows fluency with ICD-10-CM's structure, conventions, and sequencing rules across realistic documentation — not code memorization.

## Project 1: Chapter Deep-Dive Coding Set

**Level:** Beginner | **Time:** 2 days

Pick one ICD-10-CM chapter (e.g., Diseases of the Circulatory System, Endocrine Diseases) and code 15-20 encounter scenarios drawn specifically from that chapter, applying its chapter-specific guidelines.

### Steps

1. Choose one ICD-10-CM chapter and read its chapter-specific guidelines
2. Collect or write 15-20 scenarios whose diagnoses fall in that chapter
3. Code each scenario, applying both general conventions and the chapter-specific rules
4. Note any combination-code situations (a single code capturing two related conditions) you encounter

### Skills Demonstrated

- Chapter-specific guideline application
- Convention interpretation within a focused domain
- Combination-code recognition

### Note

Chapter content and guidelines are revised on an annual cycle — **verify chapter-specific rules against a current-year ICD-10-CM Official Guidelines document**, since specific code assignments in an older source may no longer be current.

## Project 2: POA Indicator and HCC Risk-Adjustment Practice

**Level:** Intermediate | **Time:** 3-4 days

Work through 10+ inpatient scenarios assigning present-on-admission (POA) indicators, and separately identify which diagnoses in a set of outpatient/chronic-condition scenarios would be relevant to HCC (Hierarchical Condition Category) risk adjustment.

### Steps

1. Build or use 10+ inpatient encounter scenarios and assign the correct POA indicator to each diagnosis
2. Separately, review 10+ chronic-condition scenarios (e.g., diabetes with complications, CHF, CKD) and identify which diagnoses would map to an HCC category
3. Explain, for at least 3 scenarios, how a more specific diagnosis code (vs. an unspecified one) changes the HCC risk-adjustment outcome

### Skills Demonstrated

- POA indicator assignment
- HCC risk-adjustment awareness
- Specificity's effect on risk-adjustment coding

### Note

**Verify current HCC model version and category mappings against current CMS guidance** — HCC models are updated periodically (e.g., version changes affecting which codes map to which categories), and this project should be framed as demonstrating the *concept*, not a memorized, unchanging mapping.

## Project 3: Full ICD-10-CM Audit Portfolio

**Level:** Advanced | **Time:** 1 week

A comprehensive coding audit spanning multiple chapters, inpatient and outpatient settings, POA assignment, and self-audit — the centerpiece project for an ICD-10-CM-focused portfolio.

### Steps

1. Select 20+ scenarios spanning at least 3 different chapters
2. Code each completely, including sequencing and POA where applicable
3. Self-audit the full set a week later, documenting every correction and its cause
4. Write a short reflection on which convention or guideline caused the most rework

### Skills Demonstrated

- Cross-chapter ICD-10-CM coding
- Self-audit discipline
- Written coding rationale under review

### Portfolio Artifact Name

`icd-10-cm-audit-portfolio`

## Tips for Great Projects

**Work from documentation, not a code list.** Deriving the code from a clinical scenario — the way you will on the job — is the actual skill being demonstrated.

**Cite the specific convention or guideline behind each code choice.** "Combination code because..." or "Excludes1 applies because..." is a far stronger portfolio artifact than a bare code.

**Track your own accuracy over time.** A visible, documented self-audit trend is a stronger signal than any single project's polish.

**Treat anything guideline- or model-specific as needing a current-source check.** ICD-10-CM content, POA rules, and HCC mappings are all revised on recurring cycles.
